# 部署指南

## 环境要求

- Linux（推荐）/ Windows / macOS，Python 3.6+（纯标准库，无第三方依赖）
- 一个可公网访问的端口（云服务器请在安全组放行）

## 快速部署

```bash
# 1. 上传仓库到服务器
git clone https://github.com/<你的用户名>/card-server.git /opt/card-server
cd /opt/card-server

# 2. 启动（首次运行自动生成 config.json 与随机密钥）
python3 app.py
# 控制台会打印管理后台账号密码和全部密钥，立即保存！

# 3. 验证
curl http://127.0.0.1:8080/health     # -> ok
```

## 生产常驻（systemd）

```bash
# 修改 card.service 里的工作目录/端口后：
cp card.service /etc/systemd/system/card-server.service
systemctl daemon-reload
systemctl enable --now card-server
systemctl status card-server
```

## 首次运行说明

首次运行会自动生成 `config.json`（随机密钥），并在控制台打印：

- 管理后台账户密码（明文仅打印一次，config 内只存 PBKDF2 哈希）
- `admin_token`（脚本调用管理 API 用）
- 默认应用的 `ks` / `gk`（客户端集成用）
- `build_key`（可选的脚本密钥下发能力）

数据落在 `data.db`（SQLite，自动创建），每日首次启动自动备份到 `backups/`（保留 7 份）。

## 安全组 / 端口

- 默认端口 8080，可在 `config.json` 修改后重启生效
- 云服务器（阿里云/腾讯云等）需在安全组放行对应端口
- 生产建议：套 Nginx/Caddy 反代 + HTTPS（服务端零改动，纯反代即可）

## 多应用接入流程

1. 浏览器打开管理后台，登录
2. 「应用」→ 新建应用（如：某某助手）→ 自动生成独立 ks/gk
3. 把 ks/gk 与服务器地址集成到你的客户端（见 [SDK接入指南](../docs/SDK接入指南.md)）
4. 「发卡」页选中该应用批量发卡
5. 客户端验证请求自动路由到对应应用的卡密池

## 验证部署

```bash
python3 smoke_test.py [base_url]
# 不带参数时对 http://127.0.0.1:8080 自检
# 覆盖：健康检查 / 发卡 / 验证协议+签名 / 门禁 / 无效卡 / 一卡一机 /
#       封禁解封解绑 / 批量操作 / 多应用隔离 / 鉴权防护
# 全部通过会打印「全部通过 ✓」；测试数据自动清理
```
